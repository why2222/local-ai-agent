# 模型设置：内置目录、设备分档推荐、仅下载时联网

2026-11-21 增加"模型设置"功能时决定：可选模型目录内置在应用代码中（`src/model-catalog.mjs`），不联网抓取；设备推荐按"总内存 + 是否 Apple Silicon"分档（`recommendModel`）；切换模型即时生效并写回 `config.json`；只有用户主动点击下载时才访问 Ollama 官方仓库。

原因：项目隐私边界要求正常运行不访问外网，内置目录保证离线也能浏览和切换；目录内每个模型的中文/OCR/速度说明针对本项目的中文多模态场景人工维护，比自动抓取的通用描述更准确。内存分档规则简单可解释，用户能看懂推荐理由。

## Consequences

- 新增可选模型需要修改 `src/model-catalog.mjs` 并补充能力说明，不能指望目录自动更新。
- "仅下载时联网"是继首次安装之后第二个明确的外网例外，与公网暴露无关；不要扩展成后台自动检查更新。
- 运行时切换依赖 `CONFIG.model` 可变与 `CONFIG_FILE_PATH` 写回，测试通过 `LOCAL_AI_CONFIG_FILE` 隔离真实配置。
