# 设置面板改版：紧凑列表 + 行内展开详情 + 在线目录默认折叠

2026-11-21 模型目录扩到 284 个后，全宽大卡片列表过长。先出三版设计稿（A 紧凑列表+搜索折叠、B 主从双栏、C 紧凑表格）供用户预览，用户选 A 并要求"点击行内展开详情"，按此实现。

决定：每模型一行（名称/徽标/体积/操作），顶部搜索框与类型/已下载筛选；在线目录默认折叠成一行，搜索或已下载筛选时自动展开匹配项；点击行（或名称按钮）在该行下方内联展开描述、能力四格与推荐理由。过滤与分组逻辑抽为纯函数 `public/model-view.mjs` 以便测试，下载/切换/二次确认行为不变。

## Consequences

- 展开状态用 `undefined` 作未初始化哨兵，收起后刷新不得重新展开（曾误用 null 导致收起失效）。
- 可访问性：展开操作用独立名称按钮（`aria-expanded` + `aria-controls`），不在 `role=button` 的行内再嵌按钮；重渲染后焦点恢复到展开行。
- 徽标语义分开：推荐等级用 recommended/usable/not-recommended，"纯文本/已下载"用 neutral，避免一类多义。
- B（主从双栏）未选：信息更丰富但实现量大、窄屏不友好，后续需要时可再议。
