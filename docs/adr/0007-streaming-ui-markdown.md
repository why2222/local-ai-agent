# 流式状态 UI、滚动跟随与 Markdown 渲染增强

2026-11-21 按用户预览确认的设计实现：
- 等待状态：首批内容到达前显示三点动画"正在思考…"；文档处理显示单行进度（正在处理文档 · 第 x/y 批 + 细进度条），不再把进度元素放进头像窄列（修复竖排 bug），有文档进度时不重复显示通用等待指示。
- 滚动跟随：仅在用户位于底部附近（<80px）时自动滚到底；上滑后不再强制拉回，显示"回到底部"悬浮按钮。
- Markdown：解析抽为纯函数 `public/markdown.mjs`（标题/分隔线/表格/引用/列表/代码/粗体/行内代码/链接），渲染层只负责 DOM；链接仅允许 https 与站内路径，防 javascript 协议。
- 阶段文案区分"分批处理中 → 正在汇总 → 完成"；本机模型不输出思考链，不伪造思考过程。

## 摘要输出上限（重要）

实测发现 2B 模型在含表格的摘要提示下会陷入无限生成（llama-server 高 CPU 20+ 分钟不停）。`streamChat` 新增 `numPredict` 参数，文档摘要每批与汇总限制 `num_predict = 400`，防止模型失控拖死任务；普通聊天不限制。该值同时受本机生成速度约束（约 5-10 token/s，400 token/批约 40-90 秒）。
