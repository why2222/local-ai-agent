# 在线模型目录：主动点击才联网、本地缓存、失败回退

2026-11-21 用户希望模型设置里有更多选择。决策采用"C 方案"：内置精选目录保底（13 个，多模态全档位 + 热门纯文本），"在线获取更多模型"按钮需用户主动点击（二次确认"确认连接 ollama.com？"）才访问 Ollama 官方库，解析其 HTML 生成目录并缓存到 `data/model-cache.json`，之后离线浏览；获取失败保留现有目录并回退内置。

隐私评估（用户要求后确认）：拉取目录只发送 GET 请求，不上传聊天/图片/令牌等应用数据；网络层会暴露出口 IP、DNS/SNI 域名和浏览行为，与"下载模型"同级。因此联网必须保持用户主动触发，不能做成打开面板自动拉取。

## Considered Options

- **A 只扩充内置**：零新增风险但覆盖面受限，作为保底保留而非最终方案。
- **B 打开面板自动联网拉取**：常态化无感知联网，违背隐私原则，拒绝。

## Consequences

- 官方库无公开 JSON 接口，解析依赖其 HTML 类名，页面结构变化会导致获取失败（有明确报错与回退）；实测首页一次返回 271 个模型。
- 视觉能力识别 = 官方 vision 标签 + 命名启发式（含 vision、vl 结尾、-vl、llava 开头），可能误判，以官方标签为准逐步修正。
- 远程模型 id 严格校验（`^[a-z0-9][a-z0-9.-]*$`），缓存条目逐条校验形状，半损坏缓存不会进入目录。
- 新增 `LOCAL_AI_LIBRARY_URL` 作为测试 seam，生产默认 `https://ollama.com`，不接受请求体指定地址（防 SSRF）。
