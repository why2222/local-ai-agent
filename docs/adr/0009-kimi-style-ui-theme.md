# Kimi 风格布局与深浅色主题

2026-11-22 按用户预览确认重构 UI 对标 Kimi Code：
- **布局**：侧栏新建会话/搜索为文本入口（不再大按钮），会话列表带相对时间；左下角模型状态 + 齿轮设置菜单（模型商店、主题切换）；输入框右下角为模型选择器（快速切换已下载模型或进模型商店）；顶栏移除"仅在此设备处理"提示。
- **主题**：`:root[data-theme='dark']` 覆盖 CSS 变量，支持浅色/深色/跟随系统，`localStorage('local-ai-theme')` 持久化，head 内联脚本防闪烁，系统主题变化时跟随。
- **搜索**：侧栏搜索入口展开输入框，按标题过滤会话。

## Consequences

- 新组件颜色一律使用 CSS 变量，深色通过变量覆盖适配，不再新增硬编码色。
- 模型选择器与模型商店共用 `/api/models` 数据，切换走同一 select API。
- 主题设置仅存 localStorage，不进 config.json、不上传。
