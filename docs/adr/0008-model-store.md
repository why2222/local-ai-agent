# 模型商店：统一目录、厂商分组、组合筛选

2026-11-22 按用户预览确认实现：
- **取消"在线目录"独立分组**：所有模型统一目录，内置精选与官方库按基础名去重（内置描述优先）。所有模型都本机运行，"在线"只是更新目录的动作。
- **厂商分组 + 时间排序**：厂商由模型 id 前缀推断（qwen/deepseek/gemma/llama/minicpm 等），组内按时间新到旧；精选模型维护真实发布代际（`RELEASE_DATES`），官方库模型只有"库更新时间"（非首发时间，如实标注）。
- **组合筛选**：厂商 chips 多选 + 类型（多模态/纯文本/已下载）取交集；搜索保留。
- **命名**：面板改名"模型商店"，按钮改"更新模型目录"，精选模型带"精选"标签。
